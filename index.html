01서비스 소개

하나의 노선,
세 가지 시점.

기다림에, 정보를 더하다. 라이브버스는 같은 버스 노선을 시민과 기술, 운영의 눈으로 함께 봅니다.

  1. A시민
  2. B기술
  3. C운영

  1. A시민의 시점

    정류장에서 바로,
    내 버스의 위치를.

    앱을 설치하지 않아도 됩니다. 휴대폰 웹이나 정류장에 안내된 QR로 열면 지도에서 버스 위치와 도착 예정 시간을 확인할 수 있습니다.

    1. 웹 접속
    2. 정류장 또는 버스 확인
    3. 위치·도착 정보 확인

  2. B기술의 시점

    현재 위치를 읽고,
    도착 정보를 예측합니다.

    RTK 기반 초정밀 위치정보로 버스의 현재 위치를 읽습니다. 여기에 교통상황과 날씨, 운행 데이터를 AI가 함께 분석해 도착 정보로 연결합니다.

    1. 위치정보
    2. 교통·날씨·운행 데이터 분석
    3. 도착 정보

  3. C운영의 시점

    버스 정보와 운영 현황을
    함께 살펴보세요.

    시민에게 안내되는 버스 정보와 함께, 단말 유지보수와 운행 통계처럼 운영에 필요한 현황을 통합해 관리합니다.

    1. 운행 현황
    2. 단말 유지보수
    3. 운행 통계

02이용 경험

설치 없이 열고,
내 버스를 확인하세요.

시민이 쓰는 흐름을 세 단계로 줄였습니다. 단계를 고르거나 휴대폰 화면을 직접 눌러 보세요.

라이브버스 웹 앱 설치 없음

정류장 찾기, 버스 선택, 위치·도착 정보 확인의 세 단계로 이용합니다.

서비스 체험 · 예시 화면

실제 서비스의 화면 구성과 다를 수 있습니다.

웹으로 접속
휴대폰 브라우저에서 지역 라이브버스 주소를 엽니다. 앱을 내려받거나 가입하는 과정이 없습니다.
정류장 QR로 접속
정류장에 안내된 QR코드를 휴대폰 카메라로 비추면 같은 웹 화면이 열립니다. 완주군에서 이 방식으로 안내하고 있습니다. 위 그림은 안내용 아이콘이며 스캔되지 않습니다.
